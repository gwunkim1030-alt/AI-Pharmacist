# AI Pharmacist 💊

AI 기반 스마트 건강 대시보드 — 증상 입력 및 사진을 통해 초기 대응법과 의약품 성분을 안내하는 지능형 건강 비서입니다.

## 주요 기능

- 🏠 **대시보드 홈** — 오늘의 추천 영양제, 가까운 응급의료기관 안내, 누적 상담 건수
- 💬 **스마트 건강 채팅** — 증상 텍스트 입력 또는 사진 첨부로 AI 상담 (현재 오프라인 시뮬레이터)
- 🕒 **상담 기록** — 이전 대화 기록 저장 및 재열람 (로컬 스토리지)
- 📖 **응급처치 가이드** — CPR, 화상, 염좌, 벌레 쏘임 등 단계별 가이드
- ⚙️ **환경 설정** — 앱 정보 및 개인정보 처리 방침

## 기술 스택

- **HTML5 / CSS3 / Vanilla JavaScript** (단일 파일 구조)
- [Marked.js](https://marked.js.org/) — 마크다운 렌더링
- [Google Fonts](https://fonts.google.com/) — Outfit, Noto Sans KR, JetBrains Mono
- **LocalStorage** — 상담 기록 저장

## 실행 방법

별도의 빌드 과정 없이 `index.html` 파일을 브라우저에서 열어 바로 사용할 수 있습니다.

```bash
# 브라우저에서 직접 열기
open index.html
```
